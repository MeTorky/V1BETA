## 📖 وصف المشروع | Description

**MeTORKY** هو براند عربي أصلي بشخصية **TORKY** - المفكر الطائر. راس صفراء 3D طايرة من غير جسم، بإيدين بس، في وضعية التفكير (إيد على الدقن). 

البراند مبني على فكرة **التوكل على الله + التفكير العميق + التأثير بالبصيرة**. كل كوميكس بيحمل جملة تحفيزية أو فلسفية بالعربي، بنفس التصميم الثابت: خلفية سوداء، بوردر ذهبي، نقط هالفتون سماوي/ذهبي، وفقاعة تفكير بيضاء.

### الأنظمة المبنية:

#### 1. Comics Manager V3
- أداة Offline بتعمل كوميكس مربع (1080) وعريض (1200x675)
- بتصلح مشكلة النص العربي (Wrapping + No Overlap)
- تصدير PNG مباشر

#### 2. Bulk Scheduler
- تكتب 30 جملة مرة واحدة، تطلعلك 60 صورة جاهزة لشهر كامل
- ZIP + جدول نشر CSV

#### 3. Video Studio
- يحول أي جملة لفيديو 10 ثواني مع TORKY بيتكلم
- يولد برومبت جاهز لـ Google Flow Veo 3 (First Frame + Lip-Sync Egyptian Dialect)
- نسخة CapCut كمان

#### 4. Quran Video Studio (NEW)
- ترفع مقطع صوتي (سورة ق)
- تختار تصميم إسلامي محترم (TORKY في وضعية خشوع - لا ينطق القرآن احتراماً)
- الفيديو يمشي مع الصوت: Visualizer ذهبي + نص الآيات + Zoom بطيء

#### 5. Store + Website
- متجر MeTORKY: تيشيرتات، هوديز، مجات، كابات (أسعار EGP)
- موقع metorky.com الرسمي: لاندينج بيج فخم أسود وذهبي

## 🚀 طريقة التشغيل | How to Run

كل الأدوات HTML ملفات Offline، تفتح مباشرة في المتصفح:

```bash
# Clone
git clone https://github.com/YOUR_USERNAME/MeTORKY.git
cd MeTORKY

# Open any tool
open tools/metorky_video_studio.html
# أو دوبل كليك على أي ملف HTML
```

لا يحتاج Node, لا يحتاج Server.
